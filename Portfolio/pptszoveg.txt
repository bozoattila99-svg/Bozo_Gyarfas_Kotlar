PERSON 1 (Slides 1-5)
Slide 1

“Hello everyone.
Our presentation is about the design and simulation of an enterprise network infrastructure using Cisco Packet Tracer.
The main goal of the project was to create a scalable, secure, and redundant network capable of supporting multiple company sites.”

Slide 2

“During the project, we designed a network for a medium-sized company with three different sites.
The system supports office operations, industrial environments, and IoT functionalities as well.
Each team member had a specific responsibility, such as network design, documentation, or configuration.”

Slide 3

“While designing the network, high availability and security were important priorities.
For this reason, we implemented redundant solutions, VLAN segmentation, and firewall protection.
The system is scalable, which means it can be expanded easily in the future.”

Slide 4

“The network consists of three different locations.
The headquarters handles management and the main services.
The northern site is responsible for industrial systems, while the southern site demonstrates IoT and wireless technologies.”

Slide 5

“Each site has its own hardware and service structure.
The headquarters includes routers, switches, and an ASA firewall, while the southern site contains a Raspberry Pi based IoT system.
The network is divided into multiple VLANs for better security and traffic management.”

PERSON 2 (Slides 6-10)
Slide 6

“Logical segmentation was implemented using VLANs.
Each department received its own network segment, such as administration, guest network, and IoT devices.
Inter-VLAN communication is controlled by ACL rules through a Router-on-a-Stick topology.”

Slide 7

“The network uses dynamic routing with the OSPF protocol.
Fast convergence ensures that the network quickly adapts in case of failure.
HSRP redundancy enables automatic failover to a backup router if the primary router becomes unavailable.”

Slide 8

“Security is implemented in multiple layers.
The ASA 5505 firewall filters external traffic, while ACLs provide precise access control.
VLAN isolation separates different network segments, such as the guest network.”

Slide 9

“Communication between the sites is established using MPLS and IPsec VPN technologies.
MPLS provides fast and priority-based data transmission, while the IPsec VPN creates encrypted communication over public networks.
Data security is protected with AES-256 encryption.”

Slide 10

“The IoT infrastructure is centered around a Raspberry Pi 5 server.
It runs the Home Assistant platform and the MQTT broker service.
IoT devices use encrypted MQTT communication, and ACL rules restrict unauthorized access.”

PERSON 3 (Slides 11-14)
Slide 11

“The server infrastructure includes both Linux and Windows environments.
The Linux system provides DHCP, DNS, and web services, while the Windows environment manages Active Directory and Single Sign-On features.
This allows centralized user and permission management.”

Slide 12

“The entire network was simulated and tested in Cisco Packet Tracer.
The simulation allowed us to safely verify routes, ACLs, and NAT configurations.
This helped identify possible errors before deployment.”

Slide 13

“The network functionality was verified using ping and traceroute tests.
We also tested routing accuracy and VLAN isolation.
Failed access attempts confirmed that the ACL rules were operating correctly.”

Slide 14

“In conclusion, our project demonstrates a modern, secure, and scalable enterprise network.
The system supports both traditional enterprise services and IoT technologies.
The designed architecture can provide a stable long-term foundation for a company network.
Thank you for your attention.”
